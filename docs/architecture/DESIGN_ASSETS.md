# ERP Visual Identity and Asset Manifest

## Direction

Preserve the verified circular black NUMBER EIGHT mark from the existing Flutter assets. The ERP palette is charcoal `#171513`, warm paper `#fffefa`, background `#f4f2ed` and copper `#b7782c`. English uses DM Sans; Arabic uses Tajawal. Icons are consistent 18–20px Lucide line icons with text labels for critical actions.

## Screen specifications

- **Login:** split desktop composition, generated artwork, compact credential card, environment badge and recovery path.
- **Executive dashboard:** four KPI cards, hourly cadence, channel mix, live orders, reconciliation/freshness labels.
- **POS:** product search/categories, 3-column touch cards, persistent cart/tender rail, keyboard shortcuts.
- **Inventory:** action strip, dense filterable balance table, reorder/variance states, movement drawer.
- **Accounting:** period banner, cash/VAT/revenue cards, journal table, balance validation and close controls.
- **KDS:** station columns, high-contrast timers, sound/offline controls, large touch transitions.
- **Empty/error/loading:** code-native panels and skeletons; original illustrations only where they improve orientation.

## Generation prompt

Use case: stylized-concept. Asset type: desktop ERP login background. Premium abstract restaurant operations composition on deep charcoal, with copper-gold flows suggesting an abstract eight, coffee aroma, inventory flow and connected restaurant stations; refined matte 3D enterprise aesthetic; wide layout with negative space; no text, letters, logos, trademarks, people or watermark.

Product imagery, module empty states and additional background art are specified but not generated in this foundation; real product photos require owner-provided rights-cleared assets and a catalog photography standard (consistent 4:3 crop, neutral warm background, no third-party packaging/marks, WebP delivery with alt text).
